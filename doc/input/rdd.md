# 🎯 プロジェクト概要
## コンテキスト（AI用）
- 目的: キャラクター「524」の魅力を最大限に引き出す、体感・操作連動型のインタラクティブWebミュージックビデオ（Web MV）を創出する。
- 背景: 「524」のポップで愛らしく、どこかシュールな世界観を、静止画にとどまらず音楽・アニメーション・触感（インタラクション）と一体化させ、ユーザー自身が524とセッションする感動を届ける。
- 想定ユーザー像: キャラクター「524」のファン、Webクリエイティブ・インタラクティブ表現を楽しむすべての人。

## 人間レビュー用
- なぜこのプロジェクトを作るのか: 単なる動画視聴ではなく、「触れると音が鳴り、524が跳ね、世界が踊る」Webならではの能動的な感動体験を作るため。
- どんなユーザーのどんな課題を解決するのか: 見るだけの動画から「自分でグルーヴを操り、524と遊べる」没入体験への進化。
- **一言まとめ:** 「さわって、はずんで、音になる。524とセッションするインタラクティブWeb MV」

---

# 🧑‍💻 ユースケース
## コンテキスト（AI用）
- シナリオ1: ページを開くと、アンビエントな波紋と静かなスカイブルー。クリックまたはタップで524が目を覚まし、ビート（キックとベース）が始動。
- シナリオ2: 画面をドラッグすると524がぷるんと伸びてポーンと跳ね、ペンタトニックのきらめくシンセアルペジオが追従。
- シナリオ3: スペースキーやタップで「FEVER MODE」突入！シーンがサイケデリック＆ポップなネオンや分身ドロップレットに変化し、グルーヴが最高潮に。
- MVP範囲: **ビート同期アニメーション + 触感インタラクション + Web Audio APIリアルタイムシンセBGM + シーン演出（Intro/Groove/Fever）**

# 🏗️ 機能要件
## コンテキスト（AI用）
1. **524 キャラクタ・リアクティブレンダラー**:
   - 原作の手描き感と質感を保ちつつ、Squash & Stretch（伸縮）、まばたき、視線追従、浮遊影の連動。
   - 目の「5」「2」「4」の個別リアクション（音に合わせてスロット風に回転、ウインク、拡大）。
   - ドロップレットの物理シミュレーション（しずくが落ちて波紋と音を鳴らす）。
2. **Web Audio API プロシージャル・シンセトラック**:
   - 4つ打ちキック、ウォームなシンセベース、チルなコードパッド、リズミカルなプラック。
   - インタラクティブ音源: マウス位置（X: フィルターカットオフ/音高、Y: リバーブ/ディレイ量）、クリック/キー押下でスケール同期チャイム。
3. **シネマティックMV演出＆タイムライン**:
   - 音楽の小節（Bar/Beat）に同期したカメラズーム、背景グラデーションパルス、フローティングリリック/メッセージ（"5-2-4 GO!", "FEEL THE GROOVE", "POYON" 等）。
4. **UI & コントロール**:
   - 再生/一時停止、BPM変更（Chill 90 / Pop 118 / Turbo 135）、モード選択（Normal / Fever / Ambient）。
   - サウンドON/OFFトグル、Reduced Motionトグル、フルスクリーン切替。
   - キーボード操作（Space: ジャンプ/ビート、1〜5: 音階トリガー、F: フィーバー）。
